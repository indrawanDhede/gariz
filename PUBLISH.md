# Publish Checklist

## Opsi 1: Vercel

1. Login ke Vercel.
2. Klik `Add New Project`.
3. Hubungkan repository GitHub untuk proyek GariZ.
4. Pastikan framework terdeteksi sebagai Vite.
5. Deploy.
6. Salin URL public yang diberikan Vercel.

## Opsi 2: GitHub Pages

1. Pastikan repository sudah ada di GitHub.
2. Push branch `main`.
3. Aktifkan GitHub Pages dengan source dari GitHub Actions.
4. Tunggu workflow selesai.
5. Buka URL Pages yang muncul di repo.

## Catatan

- Proyek ini sudah disiapkan sebagai static site.
- Tidak butuh backend untuk tampil online.
- Upload lagu saat ini masih local preview di browser.
